# LLM-red-team-assessment
LLM prompt injection red-team assessment using Garak, mapped to OWASP LLM Top 10


## Overview
Comprehensive security assessment of Claude Opus 5 using NVIDIA Garak, identifying vulnerabilities mapped to OWASP LLM Top 10.

## Objectives
- Identify and document LLM vulnerabilities using industry-standard tools
- Map findings to OWASP LLM Top 10 framework
- Analyze attack vectors and security implications
- Demonstrate offensive security skills for portfolio

## Tools & Technologies
- **NVIDIA Garak** — LLM vulnerability scanner v0.17.0
- **Claude Opus 5** — Target model
- **Python 3.14.8** — Environment
- **OWASP LLM Top 10** — Vulnerability framework
